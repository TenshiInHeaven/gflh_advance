# 漏洞报告与使用边界

## 报告

- 不要在公开 issue / 讨论区贴 `uid`、`sign`、`creds_latest.json`、完整本机路径或截图中的凭证。
- 建议只提供：版本（vX.Y.Z）、复现步骤、影响描述、是否可稳定复现；需要时再私下交换敏感细节。
- 本项目是个人本地工具，没有专职安全响应团队；会尽量确认与修复，但不承诺 SLA。

## 适用边界

- 仅用于**自己本机、自己的游戏账号**的研究/学习。
- 不要把服务暴露到公网/局域网（`--host` 已限制 loopback）。
- 不要把数据目录（尤其 `creds_latest.json`）放进同步盘、网盘、公开仓库或发给他人。
- 直接调用游戏接口增删收藏标靶违反游戏服务条款，存在封号风险；请自行评估并避免在主账号/线上环境滥用。
- 本仓库预构建数据来自游戏客户端（版权归原权利方），仅作本地数据索引/展示用途。

## 已知非漏洞

- 本机同用户进程能读 `creds_latest.json`：Windows 同用户权限下无法彻底阻止，建议配合 DPAPI/ACL。
- 用户自己把端口转发、改 `--host`、上传凭证导致的风险。
- 游戏官方检测到第三方注入导致的处罚。
