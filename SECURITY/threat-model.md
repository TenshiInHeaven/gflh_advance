# 威胁模型

## 资产

| 资产 | 说明 |
|---|---|
| 游戏 uid / sign | 可调用游戏接口（含收藏标靶 add/del）；sign 会过期，但有效期内可被滥用 |
| 本机系统代理 | 应用可设置/还原代理；被篡改会影响本机所有 HTTP(S) 流量 |
| 游戏进程 | 应用可强杀/通过 Steam 重启游戏 |
| 收藏标靶 | 35 个游戏内靶机槽位；可被增删/清空 |
| 本地路径/凭证元数据 | 游戏安装路径、数据目录、凭证列表等 |
| 预构建游戏数据 | 关卡/怪种/图标（非机密，但有版权与完整性风险） |

## 信任边界与攻击者

1. **恶意网页 / 浏览器扩展**（最高优先级）：用户开着 TargetForge 时访问任意网站，网页可向
   `http://127.0.0.1:8765` 发请求；通过 CSRF 或 DNS rebinding 达成操作/读取。
2. **同机其它低权限进程**：可读数据目录、修改本地文件、连接 localhost 端口；Windows 同用户下无强隔离。
3. **局域网设备**：仅在用户错误使用 `--host 0.0.0.0` / 端口转发时可达；默认 loopback 不可达。
4. **依赖供应链**：PyPI 包（gflzirc）或预构建数据被替换/投毒。
5. **本机完全被控**：不在防护范围（攻击者已拥有同等权限）。

## 攻击路径与影响

| # | 路径 | 前置条件 | 影响 | 现状态 |
|---|---|---|---|---|
| 1 | 跨站 POST：恶意页面用 `text/plain` 简单请求调用 `/api/execute`、`/api/capture/start`、`/api/game/restart` | 应用运行 + 用户访问恶意页 | 增删游戏靶机、改系统代理、重启游戏 | 已阻断：POST 强制自定义头 + Origin + Host + JSON Content-Type |
| 2 | DNS rebinding：攻击者域名解析到 127.0.0.1，读取 `/api/creds`、`/api/sequence`、`/api/game/status` 并调用 POST | 应用运行 + 用户访问攻击者域名 | 泄露 uid/本机路径、执行操作 | 已阻断：Host 白名单；Origin 校验 |
| 3 | 局域网直连 | 用户以 `--host 0.0.0.0` 启动 | 同网段完全控制 | 已阻断：拒绝非 loopback host |
| 4 | 读取明文 `creds_latest.json` | 同用户进程/同步盘/备份/误提交 | 盗用 sign 调用游戏接口 | 部分缓解：不通过 API/日志返回 sign；**未加密**（见 hardening） |
| 5 | UNC 路径：提交 `\\attacker\share` 作为游戏目录 | 恶意网页能调用 confirm | 触发 SMB 认证，泄露 NTLM 哈希 | 已阻断：拒绝 UNC/网络路径 |
| 6 | 弹窗 DoS：反复调用 `/api/game/pick` | 恶意页面/本机进程 | 反复弹文件夹选择框 | 未做频率限制（后续可加） |
| 7 | 依赖投毒：安装被篡改的 gflzirc | 供应链被攻破 | 任意代码执行 | 未做 hash 锁定（固定版本但无校验） |
| 8 | 数据投毒 / XSS：替换数据目录内容 | 本机写权限 | 前端渲染恶意内容/脚本 | 已加 CSP；文本渲染仍需持续审计 |
| 9 | 游戏条款风险 | 使用注入功能 | 账号处罚/封禁 | 非漏洞；见 disclosure |

## 不在防护范围

- 本机已被完全控制（同用户恶意程序可直接改文件/内存）。
- 用户主动把服务暴露到公网/局域网。
- 游戏官方对第三方注入的检测与处罚。
- 用户把 `creds_latest.json` 上传/同步/提交到公开位置。
