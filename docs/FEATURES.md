# 详细功能说明

> 主页 README 只保留功能概览；这里是每项功能的细节。

## 关卡图鉴与结算

- 7 组 121 章 2345 关：主线 / 活动（含往期复刻、特殊作战）/ 积分关卡 / 教学 / 模拟作战 / 灰域探查 / 无固定关卡。
- 积分关卡按 `mission.event_score` 结算配置精确标记，混合活动会拆出「XX · 积分关卡」章
  （如 思域迷航 · 积分关卡：禁止喂食 / 禁止喂食EX）。
- 每个关卡显示「结算形式」：积分结算（event_score 模式/参数数量、score_prize 积分奖励、rank 常驻积分榜）
  或普通结算；由 STC 结算字段决定，不靠名字/加号猜。
- 复跑分析：`python targetforge/tools/analyze_score_stages.py`。
- 章节卡 → 关卡列表 → 该关可收藏队伍，支持「整关全部加入序列」。

## 怪种、全怪组与搜索

- 怪种图鉴：264 个图鉴怪种，每只有从本机游戏资源提取的真实头像（透明底 160px）；
  可按阵营 / 固定关卡 / 灰域 / 无固定关卡筛选，详情列出所有怪组并分页。
- 全怪组总表：13,700 支可收藏怪组，按编号 / 效能 / 单位数 / 总血 / 怪种数排序；
  支持章节、怪种（多个为 AND）、角色、单位数区间、效能区间/只看有标注等组合筛选，表头排序、分页、行内详情/加入序列。
- 按编号搜索：顶栏输入 `6363006` / `#6363006` 直接出队伍卡并可加入序列；序列页/序列面板也有「按编号加入」。
- 效能筛选：灰域队伍、关卡队伍、怪种详情、无固定关卡、当前靶机均支持；客户端只有积分关卡/部分特殊队伍带效能，
  其余显示「未标注」，不伪造数值。

## 灰域

- 按玩家口径：区域 → 节点 → 节点内队伍。
- 4 个区域：沙尘带 / 风暴带 / 硅状带 / 结晶带；另有装甲突击（爬塔，10 个节点，单独入口）
  与特殊区域（316 个节点；组5/6 客户端无区域名，不编造）。
- 点区域看该区域 N 个节点（标题 / 地点小字 / 难度 / 队伍数 / 怪种图标），点节点进入队伍列表。

## 支援队伍与机场候选

- 支援队伍：`spot.ally_team_id` 的支援梯队并入对应关卡队伍列表（顶部「敌方 X · 支援 Y」，支援卡带徽标，可加入序列）；
  队伍详情「本怪组出现位置」列出该怪组在各关卡的敌方/支援身份。
- 机场/后续刷新候选（推断）：STC 没有显式机场刷新池映射；按同关卡引用队伍 ID 的**最短公共前缀（3~6 位）**推断，
  前缀无候选时用引用 ID **±20 邻近窗口**兜底。候选默认折叠、标「机场可能刷新（推断）」，可展开/加入序列。
  80 条是项目自设的列表上限，不是游戏规则。
- **显式固定/刷怪表**：对已有可靠表的关卡（目前：铁雨礼赞），用 `targetforge/manual_spawns.json`
  列出该系列全部可能怪组：表中固定/刷怪组显示类型与基础效能，表中没有的标为「未实际出现怪组」；
  不再使用「社区表」标签，也不受 80 上限影响。
  已知例子：谜境守卫+ 的 AA-02 队 6363057/6363060、静默沙盘的威廉队 770060、
  潘洛斯的 Hebe/Styx 660002/660003、坠入兔洞+ 的 2141~2146。

## 序列、注入、抓取与教程

- 序列编排：加入/移除/拖拽排序/从当前靶机导入；上限 35，实时显示总单位 / 总血量。
- 执行注入：预览（删除 / 新增 / 保留 / 最终 1..N 列表 + 警告），支持追加 `append` / 按序号替换 `replace` /
  清空重排 `rebuild` 三种模式 + 清空全部 + 演练模式（dry-run，不联网）；有 job 日志，完成后引导大退重登，
  并提供「重启游戏」按钮（二次确认）。
- 登录抓取：内置向导启动本地抓包代理（端口可配置，默认 18080）→ 设置系统代理并重启游戏 → 抓 uid / sign / 当前靶机
  → 关闭代理；也可加载历史凭证。
- 教程：首次进入 6 步新手引导；教程页含概念、完整流程、抓取分步、三种执行模式、11 条 FAQ、安全须知。

## 数据规模（当前国服客户端）

- 7 组 121 章（活动 73 + 积分关卡 25）/ 2345 关 / 13,700 支可收藏队伍 / 264 个可收藏怪种。
- 灰域 4 区域 + 装甲突击 + 特殊区域 / 1288 节点 / 3352 队。
- 无固定关卡 4381 队（含支援队伍归位后 3802 队）/ 支援梯队 864 支（818 可收藏，329 个关卡有支援链接）。
- 机场/后续刷新候选（推断）2178 个关卡有候选，覆盖 7742 支同系列未入场队伍（prefix 1990 / neighbor 188）。
