# TargetForge v1.17.0 更新说明

## 关卡级屏蔽

- 灰域区域节点列表新增「无收藏队伍节点」折叠区，默认屏蔽；
- 屏蔽节点不是删除，展开后仍可点开查看红框队伍；
- 屏蔽节点和正常节点共用当前搜索、排序、点位类型筛选条件；
- 章节关卡列表也会把整关没有可收藏队伍的关卡归入「已屏蔽的关卡」。

## 关卡内分级屏蔽

关卡内的「已屏蔽（过滤）」拆为两级：

- **一级屏蔽 · 原关卡候选**：原关卡实际非红框队伍 + 本关候选小怪；
- **二级屏蔽 · 其他无关怪组**：表外/无关候选，单独折叠，避免想打特定怪组时被大量无关怪组混在一起。

## 数据与便携版

- catalog 新增 `collectable_team_count` / `noncollectable_team_count` 并重建；
- 新增自包含便携版构建脚本：`scripts/build_portable_release.py`；
- 新增便携版说明：`docs/PORTABLE_BUILD.md`；
- 便携包内置 Python 3.14.7 和运行依赖，解压后双击 `Start TargetForge.bat` 即可使用，无需系统 Python。

## 其他

- 更新 `docs/UPDATE_SUMMARY.md`，归档启动器、STC 数据核查、桥接实验、UI/主题和关卡屏蔽变化；
- 普通用户不需要原始 STC，也不需要抓包；便携包内置预构建 catalog；
- 原始 STC 仅供维护者本地重建 catalog，不随公开便携包上传。
