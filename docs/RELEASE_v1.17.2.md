# TargetForge v1.17.2 更新说明

## 桥接修复

- 修复 `bridge_addon.py` 数据目录多跳一级的严重问题：
  - 之前 addon 指向仓库上一层 `dataMiner`，读不到界面写入的 `inject_targets.json`；
  - 表现为桥接启动正常但 `APPEND bridges=[]`，静默不注入；
  - 现在统一使用 `<仓库>/dataMiner/derived/targetforge`，支持 `TARGETFORGE_DATA_DIR`。
- addon 读取目标失败时写入 `TARGETS_READ_FAILED` / `TARGETS_EMPTY`，不再完全静默。
- 注入模式空目标不再静默回退到默认 BOSS；前后端都会拒绝。
- 停止桥接时若没有代理备份，不再盲目关闭系统代理。
- 新增 `tests/test_bridge_paths.py` 回归测试。

## 桥接界面

- 移除手动输入怪组批次，桥接直接共用右侧「序列编排」；
- 序列含红框时整组按临时桥接处理；
- 普通序列执行入口在含红框时标注「强制执行注入（红框会失败）」并提示改用桥接；
- 修复模式/客户端下拉每 3 秒被状态轮询重置的问题。

## 启动器

- 候选端口改为合法且可用的 `9178 / 7813 / 9191`，移除超出 65535 的旧端口。
